Remote Terminal Security Policy

High-Risk Permission · Explicit User Consent Required

Enabling Remote Terminal Access allows your paired phone to execute arbitrary Windows PowerShell commands directly on this PC over local Wi-Fi.

  • Anything sent from the phone can read, modify, or permanently delete files, install software, or change system settings.
  • You are granted full control strictly at your own discretion. If anything unintended happens, you alone are responsible — Nexus and its developer hold zero liability.

AI Terminal Proposal Policy

Strict Opt-In · Manual UI Approval Required

Enabling Allow AI Terminal Proposals lets Nexus AI suggest single-line Windows PowerShell commands when fast local commands cannot handle a request.

  • Destructive commands (delete, format, registry deletion, diskpart) are strictly blocked.
  • AI can NEVER auto-execute shell commands from voice alone — every suggested command waits in AI & Keys until you review it and click Run.
